# E-commerce Performance Story – Tableau Dashboard

## Project Overview
This project is an interactive Tableau dashboard analyzing e-commerce sales, profitability, and regional performance using the Sample Superstore dataset.

## Features
- KPI cards for Sales, Profit, and Profit Ratio
- Monthly sales trend analysis
- Regional sales performance visualization
- Sales vs Profit scatter plot
- Interactive dashboard filter actions
- Tableau Story presentation

## Key Insights
- West region generated the highest sales
- Some categories showed high sales but weaker profitability
- Monthly trends revealed consistent business growth patterns
